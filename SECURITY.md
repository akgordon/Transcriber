# Security policy

## Supported versions

The `main` branch is the only supported line. Please report issues against current `main`.

## Reporting a vulnerability

Do not open a public GitHub issue for security problems.

Use [GitHub's private vulnerability reporting](https://github.com/akgordon/Transcriber/security/advisories/new) for this repository. Include:

- A description of the issue and impact
- Steps to reproduce
- Affected version / commit if you know it

You should get an acknowledgement when the report is received. Please give a reasonable window to patch before any public disclosure.

This app is intended to run locally and not send audio off-machine. Reports that transcription or download unexpectedly contacts the network are in scope.
